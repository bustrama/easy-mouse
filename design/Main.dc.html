Build your own remote.

A remote is a small text file: buttons, sliders and actions. Make one for Plex or Stremio in minutes, or share it with a pull request. No code runs, and anything risky asks you first.

"name": "Stremio",
"target": { "process": "stremio*.exe" },
"layout": [
{ "type": "button", "icon": "play",
"action": { "do": "smtc", "cmd": "toggle" } },
{ "type": "slider", "bind": "volume" }
]

Ready in a minute.

Install, scan the QR, click Allow. That is the whole setup.
