# Design source

Exported from the Claude Design canvas "Easy Mouse Design". Each `.dc.html` is
one artboard: `Main` is the landing page, `Desktop-*` are the PC windows,
`Phone-*` are the phone web app screens. Colours, type (Heebo) and spacing are
the reference for the real implementation. They are design mock-ups, not
production code: markup uses `x-dc` holes (`{{ }}`) and `sc-for`.

Palette: ink `#0E1116`, surface `#171C24`, border `#2A323E`, text `#F3F5F7`,
muted `#9AA4B2`, primary `#2563EB`, accent `#5B8CFF`.
