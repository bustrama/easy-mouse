הטלפון שלך הוא השלט.

שליטה במחשב Windows מכל דפדפן בטלפון. אנדרואיד או אייפון, בלי להתקין כלום בטלפון, ושום דבר לא יוצא מהרשת הביתית.

יותר ממשטח מגע.

  • משטח מגע

    הזזה, לחיצה, גלילה וגרירה במחוות טבעיות, עם השהיה נמוכה.

  • מקלדת

    הקלדה בכל שפה, כולל עברית, וגם Ctrl, Alt, Win וקיצורי מקשים.

  • מדיה

    הפעלה, השהיה, דילוג ועוצמת שמע לכל מה שמתנגן, עם שם היצירה על המסך.

  • שלטים מותאמים

    שלטים מוכנים ל-Plex ול-Stremio, ועורך פשוט לשלט משלך.

  • מתחבר מחדש לבד

    סורקים פעם אחת. אחר כך הטלפון מוצא את המחשב בלי קוד.

  • גם חלונות מנהל

    שליטה אופציונלית בחלונות מנהל ובהודעת UAC, כבויה אלא אם תאפשרו.

נשאר ברשת שלכם. תמיד.

טלפון שיכול להזיז את העכבר צריך הגנה אמיתית, גם בבית. האבטחה היא חלק מהתכנון, לא תוספת.

  • בלי ענן, בלי חשבונותהטלפון מדבר ישירות עם המחשב. שום דבר לא נשלח למקום אחר.
  • אתם מאשרים כל מכשירטלפון חדש צריך את האישור שלכם במחשב, עם קוד תואם.
  • מוצפן וחסין להשמעה חוזרתסיסמאות שמקלידים אינן קריאות למי שנמצא איתכם באותה רשת Wi-Fi.
  • ביטול בלחיצה אחתמסירים טלפון בכל רגע, או מנתקים הכול עם קיצור מקשים.
  • קוד פתוחקראו כל שורה. הגרסאות נבנות בפומבי וחתומות.

בנו שלט משלכם.

שלט הוא קובץ טקסט קטן: כפתורים, מחוונים ופעולות. אפשר ליצור אחד ל-Plex או ל-Stremio תוך דקות, או לשתף אותו ב-pull request. שום קוד לא רץ, וכל דבר מסוכן מבקש אישור קודם.

"name": "Stremio",
"target": { "process": "stremio*.exe" },
"layout": [
  { "type": "button", "icon": "play",
    "action": { "do": "smtc", "cmd": "toggle" } },
  { "type": "slider", "bind": "volume" }
]

מתקינים, סורקים את ה-QR, לוחצים אישור. זו כל ההגדרה.
